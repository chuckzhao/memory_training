# Name-Face Association Training

Learn to remember names and faces - one of the most valuable real-world memory skills!

---

## Why This Matters

- **Social success**: People appreciate being remembered
- **Professional advantage**: Essential for networking
- **Confidence builder**: No more embarrassing name blanks
- **Practical skill**: Use it daily

---

## The Name-Face Memory System

### Step 1: Pay Attention
- **LOOK** at the person's face
- **LISTEN** to their name
- **Ask** them to repeat if unsure

### Step 2: Find a Distinctive Feature
Look for the most memorable aspect:
- Eyes (color, size, shape)
- Nose (large, small, curved)
- Hair (style, color, texture)
- Mouth (smile, teeth, lips)
- Face shape (round, angular, long)
- Distinctive marks (glasses, freckles, dimples)

### Step 3: Create an Association
Connect the name to the feature using:
- **Sound-alike words**: "Barry" → "Bear-y" (hairy)
- **Meaning**: "Rose" → visualize roses
- **Rhymes**: "Jake" → "cake"
- **Alliteration**: "Tall Tom", "Friendly Frank"

### Step 4: Visualize
Create a vivid mental image combining the feature and association

### Step 5: Review
Mentally recall the person's name several times during your first meeting

## Practice Tips

1. **Use their name immediately**: "Nice to meet you, Sarah"
2. **Repeat in conversation**: "So Sarah, what do you do?"
3. **Use alliteration**: "Tall Tom", "Friendly Fran"
4. **Be creative**: The weirder the association, the better
5. **Review mentally**: Go through names at end of event
6. **Write them down**: After the meeting, note names and features
7. **Social media help**: Look at photos to reinforce memory
8. **Practice regularly**: Use these exercises weekly

---

## Common Mistakes to Avoid

1. **Not paying attention** - Focus during introduction
2. **Being too generic** - Find SPECIFIC features
3. **Weak associations** - Make them vivid and bizarre
4. **Not reviewing** - Review within 24 hours
5. **Being embarrassed to ask** - Better to ask than guess wrong
6. **Passive learning** - Actively create associations
7. **Giving up too quickly** - This skill improves with practice
