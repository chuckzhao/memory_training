## Memory Techniques for Patterns

### 1. Chunking
Break patterns into smaller, memorable groups
- Instead of: ■□■□■□■□
- Think: (■□) (■□) (■□) (■□)

### 2. Find the Rule
Look for underlying patterns
- Checkerboard pattern
- Diagonal lines
- Symmetry
- Repeating sequences

### 3. Create a Story
"The pattern starts with a BLACK square, then WHITE appears, creating a CHESS board..."

### 4. Use Associations
- ■ = filled/solid/dark = "full"
- □ = empty/light = "empty"
- Create meaningful connections

---

## Practice Tips

1. **Start simple**: Master 3x3 before attempting larger grids
2. **Look for patterns**: Is it symmetrical? Repeating?
3. **Use multiple strategies**: Combine chunking with pattern recognition
4. **Draw from memory**: Don't just visualize - recreate it
5. **Increase difficulty gradually**: Add more elements slowly
6. **Practice daily**: Even 5 minutes helps
7. **Test yourself**: Cover the pattern and recreate it

## Real-World Applications

- **Remembering floor plans**: Building layouts
- **Facial features**: Patterns in faces help with name-face association
- **Game strategies**: Chess, checkers, Go
- **Design work**: Remember layouts and compositions
- **Navigation**: Remember routes and maps
- **Passwords**: Visual patterns for PIN codes
