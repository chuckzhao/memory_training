# Memory Training Quick Reference

A cheat sheet for memory techniques and tips.

---

## Top 5 Memory Techniques

### 1. Method of Loci (Memory Palace)
**Best for:** Lists, speeches, sequences
- Use a familiar location
- Place items along a mental route
- Walk through to recall

### 2. Chunking
**Best for:** Numbers, long sequences
- Break into smaller groups (3-4 items)
- Phone: 555-123-4567 not 5551234567
- Create meaningful patterns

### 3. Acronyms & Acrostics
**Best for:** Ordered lists
- HOMES = Great Lakes (Huron, Ontario, Michigan, Erie, Superior)
- Every Good Boy Does Fine = Musical notes

### 4. Story Method
**Best for:** Random word lists
- Create a vivid, bizarre story
- Connect each item to the next
- Weirder = more memorable

### 5. Visualization & Association
**Best for:** Names, faces, facts
- Create vivid mental images
- Use all senses
- Make it personal and emotional

## Quick Daily Routine (10 minutes)

**Morning (5 min):**
- Memorize today's 5-digit number
- Review yesterday's word list

**Evening (5 min):**
- Recall morning's number
- Create tomorrow's word list (10 words)
- Quick observation: describe your workspace from memory

## Remember Better: The 5 Rules

1. **Pay Attention** - You can't remember what you didn't encode
2. **Make It Meaningful** - Connect to existing knowledge
3. **Visualize It** - Mental images stick better than words
4. **Repeat with Spacing** - Review after 1 hour, 1 day, 1 week
5. **Test Yourself** - Active recall strengthens memory

## When Information Won't Stick

**Problem:** Can't remember names
**Solution:**
- Repeat name immediately
- Create face association
- Use name in conversation 3 times

**Problem:** Forget what you read
**Solution:**
- Take notes while reading
- Summarize after each section
- Teach it to someone else

**Problem:** Lose focus while studying
**Solution:**
- 25-min focused sessions (Pomodoro)
- Remove distractions
- Active note-taking
- Change locations

**Problem:** Remember short-term, forget long-term
**Solution:**
- Spaced repetition (review at intervals)
- Use multiple study sessions
- Sleep after learning
- Test yourself regularly

## Emergency Memory Hacks

### For a Test Tomorrow
1. Focus on key concepts, not details
2. Create simple acronyms
3. Teach material to friend/mirror
4. Get good sleep (don't cram all night!)
5. Review notes right before bed

### For Remembering Right Now
1. Repeat info out loud 3 times
2. Write it down immediately
3. Create a vivid mental image
4. Connect to something you already know
5. Use phone/notes as backup

### For Long-Term Retention
1. Review after 1 day, 3 days, 1 week, 1 month
2. Use information practically
3. Teach it to others
4. Create flashcards
5. Make it relevant to your life

## Red Flags: When to See a Doctor

Serious memory concerns:
- Forgetting recent conversations completely
- Getting lost in familiar places
- Difficulty with routine tasks
- Confusion about time or place
- Personality changes
- Sudden memory decline

Normal aging vs. concerning:
- ✓ Normal: Forgetting where you put keys
- ✗ Concerning: Forgetting what keys are for

- ✓ Normal: Occasional word-finding difficulty
- ✗ Concerning: Frequent inability to express thoughts
